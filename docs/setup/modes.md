- `ask` прочитал Makefile, docker-compose.yml и README, объяснил решение и предложил текст, но файл не правил и разрешения не запрашивал.
- `code` прочитал те же файлы, автоматически выполнил разрешённый поиск и перед изменением README запросил разовое разрешение; после подтверждения файл изменил.
- Для разбора кода я выберу `ask`: он исследует проект и отвечает, не меняя рабочее дерево.
- `plan` может составлять план и изменять только файлы планов; остальные изменения файлов запрещены.
- `debug` может системно диагностировать и исправлять ошибки, используя доступные ему инструменты в рамках настроенных разрешений.
